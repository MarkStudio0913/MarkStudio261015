# MarkStudio 功能演示

这是一款 **所见即所得** 的 Markdown 编辑器，输入即时渲染。

## 文本格式

支持 **加粗**、*斜体*、~~删除线~~、`行内代码`，以及 [链接](https://github.com)。

单波浪号写法如 0~7、31~81 在阅读模式中按文字展示；`~~删除~~` 才会渲染成删除线。

## 列表

1. 顺序列表项一
2. 顺序列表项二

- 无序列表项 A
- 无序列表项 B

## 任务列表

- [ ] 待办事项一
- [x] 已完成事项二

## 表格

| 列一 | 列二 | 列三 |
| :--- | :---: | ---: |
| 左对齐 | 居中 | 右对齐 |
| a | b | c |
